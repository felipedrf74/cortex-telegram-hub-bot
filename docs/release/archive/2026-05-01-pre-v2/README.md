# Archived Release Packs

Date archived: 2026-05-01

These files were moved out of the active `docs/release` namespace during the
release-process cleanup.

They are retained for audit traceability only:

- `cooking-training/` contains the Cooking + Training release-window reports.
- `nexus-hub-rc/` contains older Nexus Hub production-candidate docs.
- `qa-remediation/` contains the round-2 QA remediation progress report.
- `smoke-evidence/` contains historical staging/prod/iOS smoke artifacts.

Do not use these files as active release gates by default. If a future release
needs one of these artifacts, link it explicitly from the current release
summary and state which evidence remains valid.
