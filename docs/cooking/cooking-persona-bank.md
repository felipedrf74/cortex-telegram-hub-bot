# Cooking Persona Bank

Date: 2026-04-30

| Persona | Needs | Primary Risks |
|---|---|---|
| Busy professional | 20-minute dinners, batch prep, grocery coherence | Unrealistic prep time |
| Training-heavy user | hard-session fueling, recovery dinners | Under-fueling or duplicate warnings |
| Budget-sensitive user | low-cost meals, substitutions | Expensive recommendations |
| Beginner cook | simple steps, limited equipment | Overly complex recipes |
| Experienced cook | flexible substitutions, variety | Generic suggestions |
| Pantry-first user | use existing items, reduce waste | Invented pantry certainty |
| Allergy/restriction user | strict avoidance | Safety-critical miss |
| Travel week user | constrained schedule, low equipment | Unrealistic cooking windows |
| Multi-tenant user | separate pantry/preferences per workspace | Tenant leakage |
| Family/shared planner | tenant-shared meal plan with private restrictions | Private preference exposure |
