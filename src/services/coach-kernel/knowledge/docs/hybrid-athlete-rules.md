# Hybrid Athlete Rules

- Endurance priority wins during race-specific build, peak, and taper blocks.
- Strength drops to minimum effective dose whenever race specificity is more valuable than hypertrophy or max-strength gain.
- Lower-body lifting cannot compromise the next key endurance session.
- If time windows collapse, keep key endurance, one quality strength touch, and one mobility reset before adding more volume.
- Hybrid athletes should accumulate progress through repeatable weeks, not heroic stacked days.
